# 🏠 装修账本

装修预算清单与记账工具。数据全部保存在本机，无账号、无联网、无广告。

## 功能一览

- **预算清单（核心）**：板块（硬装施工/全屋电器/全屋智能/家具软装/其他杂费…）→ 项目两级结构，
  每项有规格品牌、单位、数量、单价，预算总价自动计算；板块小计、全案总计、与「预算目标」的
  超支/结余一目了然——就是你的《家庭装修全案预算评估表》的在线版
- **表格内直接编辑**：点击单元格改名称/数量/单价，失焦即保存
- **实际花费两种记法**：小件在清单里填「实际单价」；定金/尾款等多次付款的大件用「订单」挂到项目下
- **从 Excel 导入**：上传你的评估表（.xlsx），自动识别板块/项目/预算目标，标注「已买」的项目自动算作实际价
- **Excel 导出**：预算评估表（含公式，可继续在 Excel 里用）+ 付款明细 + 板块汇总
- **统计图表**：板块预算 vs 实际、月度付款趋势、最近付款流水
- **票据照片**：每笔付款可附发票/收据照片；退货退款记负数自动冲抵
- **居家暖木主题**：亚麻/暖木/陶土/鼠尾草配色，深浅双模式（设置页可切换或跟随系统）
- **拖拽排序**：按住 ⠿ 手柄拖动板块或清单行直接排序
- **行内编辑即存**：点击单元格修改，失焦保存并绿色闪光确认；金额数字滚动动画

## 日常使用

**双击项目目录下的 `启动.bat`**，浏览器自动打开 `http://localhost:5174`。

- 使用期间不要关闭弹出的命令行窗口；用完关窗即可，数据实时保存
- 提示端口被占用 = 账本已在运行，直接访问 `http://localhost:5174`

## 使用流程建议

1. **建清单**：「预算清单」页添加板块和项目（或导入 Excel），填数量、单价
2. **定目标**：点顶部主卡「改目标」填总预算上限（如 160000），随时看超支/结余
3. **买东西**：一次付清的小件 → 「+订单」勾选「一次付清」，金额默认=总额，票据直接拖进去，一个表单搞定（自动记付款+结清）；不想留票据就直接勾「已买」改单价；分定金尾款的大件 → 关闭「一次付清」建订单，每次付款记一笔，票据拍照上传
4. **每周巡检**：看顶部主卡和板块小计，红色超支提醒一眼可见

## 数据在哪里？如何备份？

```
data/
├── reno.db        # 全部数据（清单/订单/付款/票据记录）
└── uploads/       # 全部票据照片
```

**备份**：关闭账本后复制整个 `data/` 文件夹；**恢复**：覆盖回来。
轻量备份：清单页「导出 Excel」。

## 常见问题

**Q: 怎么把 Excel 评估表放进系统？**
清单页「从 Excel 导入」。要求表头包含「项目名称」和「单价」列，板块行以【开头，有「预算目标」行更佳。导入是替换式的，会先清空现有清单（订单和付款保留）。

**Q: 实际单价和订单付款会不会重复计算？**
会。同一项目二选一：要么填实际单价（一次买断），要么用订单记付款（多次付款）。设置页有口径说明。

**Q: 手机能用吗？** 手机连同一 WiFi 访问 `http://<电脑IP>:5174`，界面以电脑为主。

**Q: 数据会上传吗？** 不会，完全离线可用。

## 开发相关

```bash
npm run dev        # 开发模式（前端 5173 + 后端 5174 热重载）
npm run build      # 构建前端到 dist/
npm start          # 单进程启动（托管前端+API，端口 5174）
node server/test-api-v2.mjs   # 后端场景测试（需服务运行中）
```
